Aqua Level Lab

【Windows 版：実データ取得・グラフ・海岸線付きコンター】

1. ZIP ファイルを右クリックして「すべて展開」を選びます。
2. 展開したフォルダーの AquaLevelLab.exe をダブルクリックします。
3. ブラウザーでアプリが自動的に開きます。
4. 水域・項目・開始年と終了年・季節や月・採水深度を選び「取得して表示」を押します。
5. 地図上部で値の範囲・等値線間隔・塗り分け／等値線を変更できます。
6. 地図下部から NetCDF・Shapefile・測点平均CSVを保存できます。
7. Argo・CCHDOを使う場合はデータソースで選択し、沖合水域または経緯度範囲と深度を指定します。

外部ソースの例: Argoのみ、範囲指定（西140・東141・南30・北32）、2018年、0〜20m、水温。
Argoの湾内・0〜1mは欠測の場合があります。取得失敗と観測なしは区別して表示します。
本版は SweepLine tree エラーの原因となるポリゴン演算を置き換えた修正版です。

既存版を開いている場合は一度終了し、新しく展開した版を起動してください。
起動画面は実観測解析です。2010〜2018年などの期間平均に対応しています。
補間は定常拡散方程式。密度はEOS-80の派生値です。
計算方法と研究利用上の注意: SCIENTIFIC-METHOD.md

Node.js のインストールやコマンド入力は必要ありません。
runtime フォルダーなど、同梱ファイルは同じ場所に置いてください。
実データの取得時にはインターネット接続が必要です。
起動ウィンドウの「アプリを終了」、または右上の × で終了します。

【HTML 版：デモ】

Aqua-Level-Lab-Demo.html をダブルクリックします。
サンプルデータの地図・コンター・グラフがすぐ表示されます。
この HTML ファイル単独で動き、インターネット接続も不要です。
HTML 版はサンプルデータによるデモで、実データの新規取得には対応しません。
