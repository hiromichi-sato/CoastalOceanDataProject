# Aqua Level Lab

水環境・海洋観測データを、衛星プロダクトの Level 2/3/4 に近い考え方で扱う研究ワークベンチです。

起動画面は環境省・Argo・CCHDOの実観測APIを使った解析画面です。水温・塩分・密度など25項目（項目の対応はソースごとに異なります）、期間平均、月・季節・深度選択、定常拡散方程式によるコンター、年別・月別グラフに対応しています。先にデータファイルをダウンロードする操作は不要です。

ArgoはIfremer ERDDAPから調整済み温度・塩分・圧力と派生値を取得します。CCHDO / GO-SHIPはNOAA PMEL ERDDAPから船舶CTDの温度・塩分・圧力・酸素を取得します。DARWINや気象庁からの全航海直接取得はまだ未実装で、CCHDOへの収録分のみ利用できます。

Argoの確認例: ソースをArgoのみ、水域を範囲指定、西140・東141・南30・北32、2018年、深度0〜20m、水温または密度。湾内や0〜1mにArgo観測があるとは限りません。データがない場合に検索範囲を自動で広げることはありません。

2026-09修正: `Unable to find segment ... in SweepLine tree` を起こしていた浮動小数点のポリゴン切り抜きをClipperによる整数座標演算へ置換しました。コンター形状の座標だけを格子幅の100万分の1へ丸め、計算格子の値は変えていません。旧取得画面・HTMLデモにも適用しています。

方法と制限の詳細は [SCIENTIFIC-METHOD.md](SCIENTIFIC-METHOD.md) を参照してください。

## 起動

### コンターの保存

地図の下の `NetCDF (.nc)` または `Shapefile (.zip)` ボタンで、現在の表示結果を保存できます。コンターが作成できるまでボタンは無効です。

- NetCDF: CDF-1 / CF-1.8 形式。表示と同じ格子値、1次元の緯度・経度、陸域マスク、観測固定値、セル接続を収録します。緯度は北から南への降順です。欠測は `_FillValue`、水域は `water_mask=1`、求解済みは `solved_mask=1` です。実観測解析は規則経緯度格子、局所平面近似で計算します。
- Shapefile: 色分けしたコンター帯のポリゴンです。等値線だけの出力ではありません。海岸線と地図枠で切り抜き、WGS 84 / EPSG:4326 で保存します。ZIP に `.shp/.shx/.dbf/.prj/.cpg` と `metadata.json` が入ります。属性 `lower` / `upper` は帯の下限・上限です。
- 両形式に表示時の項目、取得条件、元の観測点、補間方式を記録します。デモはファイル名とメタデータに明記します。NetCDF のメタデータは `processing_metadata` 属性内の JSON です。

**解析の前提:** 定常拡散方程式の解であり、海流・移流を再現する予測モデルではありません。海岸線と外縁は流束ゼロ、観測を含む格子は固定値です。観測のない孤立水域は欠測。格子解像度は画面サイズから独立しています。旧取得ツール `/index.html` とオフラインHTMLデモにのみ旧IDW表示が残っています。

科学計算のテスト: `npm test`。実データ画面のテスト: `node scripts/test-research.cjs`（Playwright と Edge が必要。`APP_URL` と `PLAYWRIGHT_PATH` で別環境を指定）。

コマンド入力なしで使う場合は、次のいずれかを開きます。

- `AquaLevelLab.exe`: Windows 用の起動アプリです。Node.js を同梱しているため、別途インストールは不要です。実データ取得を含むアプリがブラウザーで開きます。
- `Aqua-Level-Lab-Windows-x64.zip`: 配布用 ZIP です。「すべて展開」して、中の `AquaLevelLab.exe` をダブルクリックしてください。
- `Aqua-Level-Lab-Demo.html`: HTML ファイル単独で動くオフラインデモです。サンプルデータの地図とグラフを表示します。実データの新規取得は Windows 版を使います。

Windows 版の起動ウィンドウを閉じると、その起動アプリが開始したサーバーも終了します。使用中のポートを避けて自動で起動し、同じ実行ファイルを再度開いた場合は既存のアプリを開きます。Windows 版はこの PC 内からのアクセスを対象にしています。

開発時に従来の起動方法を使う場合は以下の手順です。

Windows では `start-windows.cmd` をダブルクリックするか、プロジェクトフォルダーの PowerShell で実行します。

```powershell
.\start-windows.cmd
```

Node.js 18 以上を自動で探します。通常のインストール先にない場合、この PC にある Codex 付属の Node.js も確認します。システムの PATH は変更しません。サーバーの起動が完了すると、既定のブラウザーでアプリを自動的に開きます。PowerShell の画面はサーバーの実行状態を表示するため、そのまま残ります。起動したウィンドウは使用中そのまま開いておき、終了時は `Ctrl+C` を押します。

Windows または WSL で `node` コマンドが使える場合は、次の方法でも起動できます。Windows と WSL の Node.js は別管理です。

```powershell
node server.js
```

## 処理レベル

- L2: 観測点、航海、フロート、検体値、鉛直プロファイルなど、観測に近いデータ
- L3: 年度、水域、自治体、測定項目、標準深度などで整理された集約データ
- L4: 複数ソースを統合した平均、季節性、補間、コンター、研究用派生プロダクト

- 神奈川県 公共用水域及び地下水の水質測定結果

## 表示機能

「グラフ・コンターを表示」を押すと、ダウンロードを経由せず ArcGIS REST API から地点データを直接取得し、平均グラフとコンター風の空間分布を表示します。

現在の直接表示:

- 東京湾、伊勢湾、大阪湾、瀬戸内海
- COD、DO、全窒素、全燐
- ソース横断の統合表示
- ソース別の分離平均

コンターには、国土地理院「地球地図日本」を基にした海岸線・陸地・島を重ねます。地図と観測点は同じメルカトル投影で描画し、補間色は陸地部分をマスクします。緯度経度、都道府県名、色の凡例を表示し、補間・観測点・地名は個別に表示を切り替えられます。

地図と描画ライブラリは同梱しているため、外部の地図配信サービスへの接続や API キーは不要です。スマホの画面幅に合わせて地図を再描画します。更新前の画面が残る場合は、ブラウザーで `Ctrl+F5` を押してください。

地図は概略背景であり、最新の埋立地や港湾形状を保証するものではありません。陸地のマスクは表示上の処理で、IDW 補間が海岸線を迂回するモデルになるわけではありません。元の観測座標は変更しません。出典・固定バージョン・ライセンスは `public/data/README.md` に記載しています。

## デモ

「L2/L3/L4 デモ」を押すと、以下を想定したサンプル統合プロダクトを表示します。

- L2: Argo、気象庁観測船、JAMSTEC 航海観測
- L3: 沿岸モニタリング
- L4: 平均グラフ、季節別平均、コンター風表示

これは実データ取得ではなく、処理設計を確認するためのデモデータです。
